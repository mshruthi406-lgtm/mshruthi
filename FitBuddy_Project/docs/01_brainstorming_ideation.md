# Phase 1 – Brainstorming & Ideation

## Project
FitBuddy – AI Fitness Plan Generator using Gemini Models

## Problem
Users often need a simple starting point for goal-oriented exercise planning. The supplied project brief proposes an AI-powered web application that turns basic fitness information into a structured 7-day plan.

## Proposed Solution
FitBuddy collects:
- Name
- User ID
- Age
- Weight
- Fitness goal
- Workout intensity

It then produces a personalized 7-day workout plan, a nutrition/recovery tip, and an optional revised plan after feedback.

## Key Scenarios
1. Generate a plan from a user's fitness profile.
2. Update the plan using feedback such as more cardio or more rest days.
3. Provide a nutrition/recovery tip.
4. Allow an administrator/coach to view stored users and plans.

## Initial Feature List
- User input form
- AI workout generation
- Nutrition tip generation
- Feedback loop
- SQLite persistence
- Admin dashboard
- API documentation
- Responsive UI

## Expected Benefit
The project demonstrates how generative AI can be integrated into a web application to create adaptive, structured fitness content.
